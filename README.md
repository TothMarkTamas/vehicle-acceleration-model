Vehicle Acceleration Model

A MATLAB-based vehicle acceleration simulation project focused on basic longitudinal vehicle dynamics.

The project is developed progressively, with each version adding new physical effects, calculations, or MATLAB functionality.

Current Model

The current model (V4) includes:

Vehicle mass
Engine power and drivetrain efficiency
Rolling resistance
Aerodynamic drag
Tire-road traction limit
Power-limited and traction-limited acceleration
0–100 km/h time estimation
Acceleration vs. speed visualization
Traction-to-power limitation transition point
